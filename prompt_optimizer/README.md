# Promptly - AI Prompt Optimizer

## Project Overview

Promptly is a web-based Prompt Optimizer that analyzes a user's prompt and improves it by checking important prompt components.

The system checks:

1. Role / Persona
2. Context / Audience
3. Clear Task
4. Output Format
5. Constraints

## Technology Stack

- Python
- Flask
- Pandas
- HTML
- CSS
- JavaScript
- CSV Dataset

## How to Run

Install dependencies:

pip install -r requirements.txt

Run dataset analysis:

python data_analysis.py

Run the website:

python app.py

Open in browser:

http://127.0.0.1:5000

## Project Type

This prototype uses a rule-based prompt optimization approach.

The dataset is used for basic analysis and testing.

Future versions can integrate Large Language Models or APIs for advanced prompt optimization.
